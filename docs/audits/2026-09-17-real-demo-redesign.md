# 설명 콘텐츠와 실제 시연의 역할 재구성

> 후속 개선: U-Boot 실습 네 개 모두에 실제 녹화를 추가했다. 아래는 첫 재구성 당시 기록이며, 최종 변경은 [실습 녹화 점검](2026-09-17-uboot-practice-recordings.md)을 참조한다.

이전 개선은 설명 슬라이드를 MP4·Remotion 영상으로 만들었다. 실행 장면이 없는 영상은 학습자가 읽는 속도를 제한하고 불필요한 재생 조작을 요구했다. 설명 자료는 읽는 형태로, 실제 사용 과정만 녹화로 구분했다.

## 전체 페이지 판단과 반영

| 영역 | 현재 형식 | 판단 |
|---|---|---|
| 오프닝 | 본문·학습 순서·실제 시연 바로가기 | 장식 영상 불필요 |
| Claude·모델 소개 | 카드·모델 표·공식 문서 | 정적인 비교가 적합해 설명 영상 제거 |
| 핵심 기능 | 기능 설명 + 수동 슬라이드 5개 | 명령·단계는 직접 넘기고 복사·정독 가능 |
| 실제 시연 | 실제 Claude Code 화면 50초 | Read → Bash 실패 → Edit → Bash 통과의 실제 사용 장면 |
| U-Boot 응용 | 요청·검토 기준 + 수동 슬라이드 4개 | 실제 보드 시연이 없는 내용은 실습 가이드로 명확히 제공 |
| 효과 측정 | 측정 항목 카드·도입 절차 | 근거 없는 수치·차트 영상 불필요 |
| 설치·시작 | OS별 명령·체크리스트 | 사용자가 복사하고 따라 할 수 있는 본문이 적합 |
| Q&A | 접고 펼치는 답변 | 시연 범위를 독립 C 예제로 정확히 갱신 |

슬라이드는 자동으로 넘어가지 않는다. 이전·다음·장 번호·좌우 방향키로 이동하며 전체 내용을 펼쳐 읽을 수 있다. 설치·모델·효과 내용은 기존 본문과 중복돼 별도 슬라이드도 없앴다. 페이지에는 수동 슬라이드 9개와 실제 영상 플레이어 1개만 남았다. 기존 설명 MP4 5개와 Remotion 8개, 생성 코드·관련 의존성을 제거했다.

## 실제 시연의 근거

- 실행 프로그램: Claude Code 2.1.274, 화면 표시 모델 Sonnet 5 / low effort.
- 별도 `/tmp/claude-code-live-demo` 디렉토리의 교육용 C 파일. 의도적으로 12비트 마스크를 8비트로 잘못 작성했다.
- Claude Code가 파일을 실제로 읽고 오류를 설명했다. 다음 요청에서 실제 컴파일·실행 실패(exit code 134), 한 줄 수정, 재실행 `4 boundary cases passed`가 기록됐다.
- 화면은 Xvfb/xterm에서 x11grab으로 녹화했다. 합성 터미널·재작성한 모델 출력이 아니다.
- 원본 124.534초에서 시작 전·응답 후 대기와 로그 탐색 사이 정지를 제거해 50초로 편집했다. 남긴 구간은 1배속·원래 순서다.
- 원본·편집본, SHA-256, 편집 구간, 한국어 VTT, 수정 전·후 코드와 요청을 저장했다. 원본 다운로드도 제공한다.
- 시연은 네 입력의 하위 12비트 추출만 검증한다. 실제 U-Boot 빌드, ECC, MMIO, 보드 테스트를 수행했다는 의미가 아니다.

## 검증

- 게시 영상의 0~49초, 1초 간격 이미지 50장을 3개 장면표로 전수 육안 확인했다. 매 프레임 검토라는 뜻은 아니다.
- 실제 코드 변경과 실패·통과 로그가 읽히는 것을 원본 크기 이미지에서도 확인했다. 34~41초·42~49초는 상세 로그를 읽는 구간이며, 응답 없는 긴 대기는 제거했다.
- 수정 전·후 파일을 별도 GCC 실행으로 확인: 이전 SIGABRT / assertion 실패, 이후 exit 0 / 네 입력 통과.
- 단위 테스트 12개 통과. 슬라이드 경계·버튼·키보드, 원본·편집본 해시·구간·자막 계약 포함.
- TypeScript 검사와 GitHub Pages base path 정적 빌드 통과.
- 실제 브라우저에서 영상 1개, 수동 재생, 5개 자막 cue, 34초 탐색 후 정지, 슬라이드 9개 클릭·좌우키 이동 확인.
- 1440px / 390px 화면에서 가로 넘침 없음. 섹션 7개 × 화면 2종의 현재 위치 표시 일치. 모바일 버튼은 장 번호와 이전·다음을 두 줄로 배치했다.
