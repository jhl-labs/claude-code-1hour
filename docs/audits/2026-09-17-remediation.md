## 검증 근거

- `pnpm test`: 8개 파일, 12개 테스트 통과. 긴 섹션 탐색과 배포 영상·manifest·큐·자막 일관성 검사 포함.
- `pnpm exec tsc --noEmit`, `pnpm typecheck:remotion`: 통과.
- `NEXT_PUBLIC_BASE_PATH=/claude-code-1hour pnpm build`: 정적 빌드 통과.
- C 예제: `cc -std=c11 -Wall -Wextra -Werror`로 컴파일하고 종료 코드0 확인. 이 결과는 ECC·드라이버·보드 검증이 아니다.
- 한국어 VTT가 브라우저에서4개 cue로 로드되는 것을 확인.
- ffprobe로 MP4 5개의 실제 길이32초, manifest 해시, 큐 범위 확인.
- 수정 후 **1초 샘플400장 / 장면표26장 전체 육안 검토**. 1초보다 짧은 모든 프레임을 검사했다는 뜻은 아니다.
- 1440×1000 / 390×1000에서 7개 섹션 탐색 확인. 문서 전체 수평 넘침 없음.
- 배포용 basePath가 적용된 정적 산출물에서도 브라우저에서 처음 정지, MP4 간 단일 재생, MP4와 Remotion 간 상호 정지,8초 장면 이동, 스크롤 재진입 후 일시정지 유지 확인.

## 재현과 유지 관리

`remotion/lesson-data.json`이 영상·큐·본문 설명의 원본이다. `pnpm demos:render`로 MP4 5개와 보조 자산을 재생성한다. 나머지8개는 Remotion Player로 재생한다. 자산의 내용 해시를 캐시 키로 사용한다. 렌더링·점검 방법은 [README](../../README.md)에 있다.

공식 출처는 페이지의 각 항목에 연결했다. 이후 모델·권한·Workflow·설치 방법을 수정할 때 확인일과 영상도 함께 갱신해야 한다.

이번 수정의 범위는 **정확한 설명과 검토 가능한 학습 자료**다. 실제 Claude의 성능을 입증하는 녹화, 해당 보드의 성공 로그, 생산성 수치는 포함하지 않는다. 그런 자료를 추가하려면 동일한 과제·소스 커밋·모델·CLI·도구 체인과 원본 실행 로그를 갖춘 별도 실험이 필요하다.

로컬 Python 기본 정적 서버는 HTTP Range를 지원하지 않아 장면 이동 검사가 실패했다. HTTP Range를 지원하는 서버에서 같은 정적 산출물을 검사해 통과했다. 검토 서버도 동영상 구간 요청을 지원해야 한다.
