# Claude Code 1시간 강의 — 콘텐츠 최신화 설계서 (2026-09)

## 0. 배경

`2026-04-28` 설계서 기준으로 플랜1~3(사이트 골격, 모션그래픽/R1 시뮬레이션, 임베디드 데모 5편)까지 구현 완료. 이후 5개월간 Claude / Claude Code가 크게 발전(Claude 5 계열 모델, Skills·Subagents·Workflows 정식화, Plugins/MCP 생태계 확대)했으나 §1(역사)·§2(핵심 기능 투어)·§5(시작하기)·QA 콘텐츠가 이를 반영하지 못하고 있음. 본 문서는 **콘텐츠와 섹션 구성의 최신화**만 다룬다 — 사이트 기술 스택, 디렉토리 구조, 데모 제작 파이프라인(vhs+Remotion)은 기존 설계서(4-28) 그대로 유지한다.

| 섹션 | 변경 여부 | 내용 |

| §3 임베디드 데모 4종 | **나레이션만 손질** | 시나리오·프롬프트·산출물 그대로, 최신 용어로 표현 수정 |

## 2. §1 역사 타임라인 (V1) 갱신 내용

기존: Anthropic 2021 → Claude 1/2/3 → Claude Code 2025-02 → "2026 현재".

신규 타임라인 포인트 (기존 뒤에 이어붙임):
1. **2025 후반** — Claude Code에 Skills(SKILL.md 기반 패키지형 워크플로우) 정식 도입.
2. **2025 후반~2026 초** — Subagents 네이티브 지원: 병렬 실행, 자체 컨텍스트/툴 권한, 중첩 서브에이전트.
3. **2026** — Claude 5 계열(Opus 5 / Sonnet 5) + Haiku 4.5 출시, 이어서 Fable 5.1까지. 코딩·장시간 에이전트 작업 품질 도약.
4. **2026** — Workflow(다중 에이전트 오케스트레이션) + Plugins/MCP 마켓플레이스 확대로 "혼자 코딩하는 도구"에서 "여러 에이전트를 조율하는 팀장 역할"로 포지션 이동.

**변곡점 3개** (기존 슬라이드 문구 유지 컨셉, 내용만 교체):
- 변곡점 1: 에이전틱 루프의 등장 (기존 유지)
- 변곡점 2: Skills/Subagents로 "일회성 대화"에서 "재사용 가능한 워크플로우"로
- 변곡점 3: Workflow 오케스트레이션으로 "한 명의 코더"에서 "에이전트 팀"으로

영상 V1 길이(90초)는 유지, 후반 15~20초 구간만 교체.

## 3. §2 핵심 기능 투어 재설계 (12분, 5개 기능)

기존 슬롯(CLI / CLAUDE.md / 도구사용 / MCP / Skills+Subagent+Hooks 묶음)을 아래로 교체:

| 순번 | 기능 | 영상 | 비고 |
|---|---|---|---|
| 1 | 에이전틱 루프 (CLI) | V2 (기존 재사용, 자막만 갱신) | 사고→도구→관찰 루프는 그대로 핵심 개념 |
| 2 | 메모리 (CLAUDE.md + 프로젝트 메모리) | V3 (기존 재사용) | "다음 세션이 이미 알고 시작" 메시지 유지, 메모리 파일 자동 축적 개념 추가 |
| 3 | **Skills** (신규 독립) | **V5-New (기존 V5 MCP 슬롯 대체)** | 폴더형 SKILL.md, 사내 워크플로우를 패키징해 재사용하는 개념 |
| 4 | **Subagents + Workflow 오케스트레이션** (신규 독립) | **V6-New (기존 V6 90초 묶음 대체)** | 병렬 서브에이전트가 각자 컨텍스트를 갖고 동시에 작업 → 결과만 리드 에이전트가 취합 |
| 5 | MCP + Plugins 생태계 | V4 위치로 이동, 내용에 Plugins 마켓플레이스 추가 | "도구 사용" 단독 영상(V4)은 폐기하고 MCP 영상에 도구 호출 흐름 축약 편입 |

**폐기**: 기존 V4(도구 사용 단독) 90초 분량은 별도 슬롯 유지 대신 MCP 영상 도입부 10~15초로 축약 편입. 기존 V6(Skills/Subagent/Hooks 90초 묶음)은 완전 폐기, Hooks는 §5로 이동.

**영상 카탈로그 변경**(기존 4-28 설계서 §4 대비):
- V4(도구 사용 60초) → 폐기, MCP 영상(V5)에 도입부로 흡수
- V5(MCP 60초) → 유지하되 Plugins 마켓플레이스 언급 추가, 길이 그대로
- V6(Skills/Subagent/Hooks 90초 묶음) → 폐기
- **V6-A (신규, Skills, 60초)**: SKILL.md 폴더 → Claude가 필요할 때 로드 → 사내 워크플로우 재사용
- **V6-B (신규, Subagents+Workflow, 75초)**: 리드 에이전트가 작업을 쪼개 병렬 서브에이전트에 위임 → 각자 결과 요약만 취합
- 기존 V0/V1/V2/V3/V7-*/V8/V9/V11은 변경 없음 (제작 방식·분량 그대로)

총 영상 편수: 기존 14편 → 15편 (V4 폐기 -1, V6 묶음 폐기 -1, V6-A/V6-B 신규 +2). 총 러닝타임은 §2 파트 기준 기존 대비 소폭 증가(≈+15초) 이내로 통제 — V4 폐기분(60초)이 V6-A/B 합(135초) 증가를 대부분 상쇄하지 못하므로, §2 전체 12분 예산 안에서 강사 해설 시간을 줄여 흡수.

## 4. §3 임베디드 데모 4종 — 변경 없음 (표현만 교정)

데모 A(레거시 분석)/C(빌드)/E(단위테스트)/H(문서화) 시나리오, 프롬프트 예시, 산출물, 강조 문구는 **그대로 유지**. 제작 파이프라인(U-Boot sandbox + vhs 녹화 + Remotion 합성)도 동일하게 유지한다. 나레이션 텍스트 중 구식 표현("도구 호출" 등 단발성 뉘앙스)이 있으면 "에이전틱 루프", "Skills로 저장해두면 다음에도 재사용" 같은 최신 맥락 문구로 자연스럽게 다듬는 수준의 텍스트 수정만 반영. 신규 데모 촬영 없음.

## 5. §4 효과 — 변경 없음

구조·표·차트(V8/V9) 그대로. 수치 갱신은 본 리팩토링 범위 밖(추후 재측정 시 별도 처리).

## 6. §5 시작하기 + 다음 7일 갱신

- 설치 영상(V11) 자체는 유지(내용 변경 없음, 설치 명령어는 그대로 유효).
- **CLAUDE.md 템플릿**에 "프로젝트 메모리는 자동 축적됨" 개념과 Skills 디렉토리(`.claude/skills/`) 안내 한 줄 추가.
- **7일 플랜**에 아래 반영:
  - 기존 항목(첫 세션, CLAUDE.md 작성, 반복 작업 자동화 등) 유지
  - 신규: "자주 쓰는 작업은 Skill로 저장해보기" 항목 추가
  - 신규: "필요하면 MCP/Plugin 하나 설치해보기" 항목 추가
- **Hooks**는 여기서 짧은 콜아웃 박스(1~2문장)로 소개 — 별도 영상 없이 텍스트로만.

## 7. QA 문항 교체

기존 QA 6문답 중 시의성이 떨어진 문항을 아래로 교체/추가 (전체 문항 수 6개 유지, 우선순위 낮은 기존 문항 1~2개를 대체):
- "Skills와 MCP는 뭐가 다른가요?" (역할 차이: Skills=재사용 워크플로우 패키지, MCP=외부 시스템 연결)
- "Subagent를 쓰면 뭐가 좋아지나요?" (병렬 처리, 컨텍스트 분리)
- "회사 코드/보안 정책상 샌드박스 필요 여부는?" — 기존 정책 톤(회의감 정면 대응 지양)은 유지하되, 최신 샌드박스 기능 존재 자체만 짧게 언급.

## 8. 작업 범위 밖

- 데모 4종 재촬영·신규 데모 추가 — 하지 않음.
- 사이트 기술 스택/디렉토리 구조 변경 — 하지 않음.
- §4 수치 재측정 — 이번 범위 밖.
- 자가학습용 확장 — 여전히 비목표.

## 9. Done의 기준 (본 리팩토링)

1. §1 타임라인 영상(V1) 후반부가 2026-09 시점까지 반영되어 재생된다.
2. §2가 5개 슬롯(CLI/메모리/Skills/Subagents+Workflow/MCP+Plugins)으로 재생되며 총 시간이 12분 ±1분 이내.
3. 폐기 영상(V4 단독, 기존 V6 묶음)이 사이트에서 더 이상 참조되지 않는다.
4. 신규 영상 V6-A(Skills), V6-B(Subagents+Workflow)가 §2 위치에서 자동재생/정지된다.
5. §3 데모 4편은 콘텐츠 변경 없이 그대로 재생된다(회귀 없음).
6. §5 CLAUDE.md 템플릿·7일 플랜·QA가 갱신된 텍스트로 렌더된다.
7. `pnpm build` 정적 빌드 성공.
