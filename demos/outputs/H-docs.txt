2. NAND read page 명령 흐름 — Mermaid sequenceDiagram
============================================================
```mermaid
sequenceDiagram
    autonumber
    participant CPU
    participant DRV as davinci_nand driver
    participant EMIF as DaVinci EMIF
    participant CHIP as NAND chip
    CPU->>DRV: read_page(page)
    DRV->>EMIF: cmd_ctrl(NAND_CMD_READ0, CLE)
    EMIF->>CHIP: command 0x00
    DRV->>EMIF: cmd_ctrl(addr0..addr4, ALE)
    EMIF->>CHIP: 5-byte address
    DRV->>EMIF: cmd_ctrl(NAND_CMD_READSTART, CLE)
    EMIF->>CHIP: command 0x30
    loop until READY
        DRV->>EMIF: read NANDFSR.READY
        EMIF-->>DRV: 0 then 1
    end
    DRV->>EMIF: 4bit_enable_hwecc(NAND_ECC_READ)
    Note over DRV,EMIF: NANDFCR.4BIT_ECC_START := 1
    DRV->>EMIF: read_buf(2048 byte) (4-byte burst)
    EMIF->>CHIP: data out
    EMIF-->>DRV: page data
    DRV->>EMIF: 4bit_readecc(hw_4ecc[0..3])
    DRV->>DRV: correct_data(buf, read_ecc, calc_ecc)
    alt syndrome == 0
        DRV-->>CPU: data, stat=0
    else correctable
        DRV->>DRV: dat[err_addr] ^= err_val
        DRV-->>CPU: data, stat=numerrors
    else uncorrectable
        DRV-->>CPU: -EBADMSG
    end
```
