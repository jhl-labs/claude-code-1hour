/tmp/claude-uboot에서 davinci_nand.c의 1-bit ECC packing(192~209행)을 실제 테스트 가능하게 분리해줘. 요구: 1) MMIO read는 드라이버에 유지하고 비트 압축/반전/3바이트 저장만 drivers/mtd/nand/raw/davinci_ecc_pack.h의 static inline helper로 추출, 원래 함수가 실제 helper를 호출하게 변경. SPDX GPL-2.0+ 유지. 4-bit ECC는 수정 금지. 2) examples/claude-demo/ecc_pack_test.c에서 그 실제 헤더를 include, 고정 경계값과 reserved bit 무시를 assert, 비트별로 조립한 독립 reference와 최소1000개 결정적 입력 비교. 호스트 cc -std=c11 -Wall -Wextra -Werror로 컴파일하고 실제 실행. 3) Python 스크립트로 임시 복사 헤더의 마스크 한 비트를 일부러 바꾼 mutant를 컴파일·실행해 테스트가 실패하는지 확인하고 원본은 보존. 4) da850evm_nand_defconfig는 4-bit ECC라 수정한 1-bit 분기를 컴파일하지 않는다는 점에 주의. 별도 build/da850-1bit-demo에 같은 defconfig를 생성하고 scripts/config로 SYS_NAND_4BIT_HW_ECC_OOBFIRST를 끄고 SYS_NAND_HW_ECC를 켠 뒤 olddefconfig로 확정해. .config를 확인하고 그 1-bit 변형에서 arm-linux-gnueabi-로 davinci_nand.o를 실제 재컴파일. 이 설정은 보드 검증을 위한 추천 설정이 아니라 코드 컴파일 확인용임을 밝혀. git diff --check도 실행. 실제 명령을 실행하고 간단히 한국어 결과를 보고해. 다른 에이전트·네트워크는 사용하지 마. 테스트는 ECC 비트 포장만 검증하고 NAND 보드는 미검증이라고 밝혀.
